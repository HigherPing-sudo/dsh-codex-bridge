Codex 反向测试先留下 saved 消息（attempts=0），正常结束当前回合，不用工具提前领取。随后实际通过 desktop 通道投递一次，在同一原线程开启不同的新回合，收到测试信封并 ack_wake，双方 pending wake 为空。没有让用户点击继续，没有用手动 idle 代替真实宿主状态。

迁移产生的旧唤醒曾阻挡新唤醒。用户授权后，在桥停止的维护窗口备份并取消旧门控，再恢复组件；历史业务、任务及预算未改。测试完成后按用户要求关闭并删除测试房间，仅保留审计记录。

本仓库不包含本机完整会话、内部推理、凭据、个人路径、真实房间/会话标识或状态备份。测试中的身份为夹具。

## 结论边界

上述记录证明本次受控联调中的功能行为。它不代替其他客户端版本、跨平台或长时间高并发环境的稳定性验证。App Tools 本地接口有版本耦合；升级后重新核对原会话连接与实际收发。
